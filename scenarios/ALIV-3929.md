h3.  ALIV-3929: [ALIV-3929] - Prompt for user credentials

_NOTE: This test case assumes that the most recent AccuLoad firmware is installed on the target device (rev 1.12).  It also assumes that the security level passwords for each level are already set via the HMI screen._

The test config provided (ALIV-3929.AL4) should have the following settings:

1. Communications -> Comm Link Programming:                    Level 5 Access
2. System Directory -> 1903 Ethernet Host Security Level:      Security Level 3
3. System Directory -> 1904 Serial Host Security Level:        Security Level 3
4. System Directory -> 1905 Communications Security Timeout:   0
5. System Directory -> 1906 Authorized Host 1:                 0.0.0.0
6. System Directory -> 1907 Authorized Host 2:                 0.0.0.0
7. System Directory -> 1908 Authorized Host 3:                 0.0.0.0
8. Serial Port Config -> Serial Port -2 Function:              MiniComp Host
9. Serial Port Config -> Serial Port -2 Baud Rate:             38400 
10. Serial Port Config -> Serial Port -2 Data/Parity:          8 Data No Parity 
11. Serial Port Config -> Serial Port -2 Control:              Remote Control 
12. Serial Port Config -> Serial Port -2 Serial Interface:     RS-232 
13. Serial Port Config -> Serial Port -2 RS-485 Duplex:        Full Duplex 
14. Serial Port Config -> Serial Port -2 Term. Resistors:      Disabled 

h4. Testing Parameter Security Passcode Access

1. Start the Accumate Application.
    Expected Result: _The application will open to a blank view._ *[PASS/FAIL]*

2. Click on the "Open" button in the top left corner of the application.
    Expected Result: _A file dialog will appear prompting the user to select a file._ *[PASS/FAIL]*

3. Load test configuration file "ALIV-3929.AL4" file.
    Expected Result: _The test configuration file will load successfully._ *[PASS/FAIL]*

4. Navigate to the System Directory -> Security Directory.  Click the "Pull Selected from AccuLoad" Ribbon button. 
    Expected Result: _AccuMate pulls the current configuration for the Security directory without prompting for credentials._ *[PASS/FAIL]*

5. Double-click Ethernet Host Security Parameter in the list view.  Change the value to "Security Level 2" and click "OK".  
   Expected Result: _A Enter passcode dialog prompt will appear._ *[PASS/FAIL]*

6. Enter the passcode for security level 1.  Verify that a popup indicating "Incorrect security level for this parameter." is displayed.  Verify after clicking "OK" that the parameter was not changed.  Use the Pull Selected from AccuLoad to verify that the parameter was not changed on the AccuLoad.
   Expected Result: _The user was informed of the insufficient security level, and the parameter was not changed._ *[PASS/FAIL]*

7. Repeat step 6 using the passcode for security level 2.  Verify that the parameter isn't changed due to insufficient security levels.  *[PASS/FAIL]*

8. Attempt to change the value of Ethernet Host Security Parameter to _Security Level 4_ using security level 3's passcode.  Confirm that the change was made to the AccuLoad.  Repeat this process several more times with different values.  Confirm that a passcode is no longer required to change this parameter.  
   Expected Result:  _After using the level 3 passcode for this paramter (set to Security Level 3), the parameter's value can be changed without further need to enter the passcode_  *[PASS/FAIL]*

9. Attempt to change the value of Serial Host Security Level (should be set to Security Level 5).  Confirm that the current security level (level 3) is insufficient to change the parameter.  
   Expected Result: _The user was informed of the insufficient security level, and the parameter was not changed._ *[PASS/FAIL]*

10. Repeat step 9 using the passcode for security level 4.  Verify that the parameter isn't changed due to insufficient security levels.  *[PASS/FAIL]*

11. Repeat step 10 using the passcode for security level 5.  Confirm that the change was made to the AccuLoad.  Repeat this process several more times with different values.  Confirm that a passcode is no longer required to change this parameter.  
    Expected Result:  _After using the level 5 passcode for this paramter (set to Security Level 5), the parameter's value can be changed without further need to enter the passcode_  *[PASS/FAIL]*

   Expected Result: _AccuMate doesn't prompt for a passcode when making changes to a parameter._ *[PASS/FAIL]*

h4. Testing Communications Security Timeout functionality

1. Connect to the Accuload via Ethernet connection.  Pull the Security Directory parameters using "Pull Selected from AccuLoad".  Confirm that Communications Security Timeout is not set to zero.  

2. Attempt to change Diagnostics Security Level to "Security Level 1".  Confirm that a passcode is required to change the parameter, and enter a security passcode.  Note the time that the parameter change occurred.
   Expected Result:  _AccuMate prompts for a passcode after making the change._ *[PASS/FAIL]*

3. Wait for approximately one minute longer than the Communications Security timeout setting (e.g. if set to '1', then wait 2 minutes to be sure).  Attempt to change back the Diagnostics Security Level to its previous setting.  Confirm that the timeout had expired.
   Expected Result:  _Accumate prompts for a passcode after the timeout has elapsed._ *[PASS/FAIL]* 

4. After entering the passcode, confirm that other parameters can be changed without reprompting the passcode dialog, as long as the timeout hasn't expired.  Each time a parameter is changed, it should reset the timer.  After changing several parameter settings, wait for the timer to expire.  Confirm that after the timeout period has been reached, AccuMate will reprompt for a passcode on the next parameter write.
   Expected Result:  _AccuMate will allow changes without requiring a new passcode each time until inactivity triggers the timeout._ *[PASS/FAIL]*
